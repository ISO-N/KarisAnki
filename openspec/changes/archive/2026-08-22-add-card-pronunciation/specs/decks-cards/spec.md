## ADDED Requirements

### Requirement: 卡片音标元数据

系统 SHALL 为卡片维护可空的 `phonetic` 字段。系统 SHALL 仅对清理 Markdown 后为单个英文单词的卡片生成音标，其他卡片 SHALL 保持 `phonetic` 为 `NULL`。卡片 API SHALL 返回该字段，且音标不得影响卡片的调度状态、重学进度或到期日。

#### Scenario: 英语单词卡生成音标

- **WHEN** 用户创建或编辑一张正面为 `apple` 的卡片
- **THEN** 卡片保存美式 IPA 音标
- **AND** 卡片 API 返回该音标

#### Scenario: 非单词卡不生成音标

- **WHEN** 卡片正面为短语、中文或普通 Markdown 内容
- **THEN** 卡片 `phonetic` 为 `NULL`

#### Scenario: 编辑卡片正面后重新计算

- **WHEN** 用户修改一张已有卡片的正面内容
- **THEN** 系统按新正面重新计算 `phonetic`
- **AND** 卡片的 `stage`、重学进度和到期日保持不变

### Requirement: 新建、编辑和导入自动生成音标

系统 SHALL 在新建卡片、编辑卡片和批量导入卡片时自动计算并持久化音标。计算过程 SHALL 使用内置的本地英语发音词典，不依赖外部词典 API 或第三方音频服务。

#### Scenario: 新建单词卡自动保存音标

- **WHEN** 用户新建一张正面为 `children` 的卡片
- **THEN** 卡片创建时同时保存对应 IPA 音标

#### Scenario: 批量导入单词卡自动保存音标

- **WHEN** 用户批量导入正面为英文单词的卡片
- **THEN** 每张可识别单词卡在导入时自动获得音标
- **AND** 不可识别行保持 `phonetic` 为 `NULL`

### Requirement: 已有卡片音标补齐

系统 SHALL 允许用户为当前卡组中的已有卡片批量补齐缺失音标。补齐操作 SHALL 只更新 `phonetic`，不得修改卡片正面、背面、调度状态、重学进度或到期日，并 SHALL 返回处理统计。

#### Scenario: 补齐卡组已有单词卡

- **WHEN** 用户对包含英语单词卡和普通卡的卡组执行补齐
- **THEN** 可识别的英语单词卡获得音标
- **AND** 普通卡保持 `phonetic` 为 `NULL`
- **AND** 系统返回已更新、已存在、未识别和无需处理的数量

#### Scenario: 补齐无权访问的卡组

- **WHEN** 用户尝试对不属于自己的卡组执行补齐
- **THEN** 系统拒绝操作并返回卡组不存在或无权访问错误

### Requirement: 复习正面展示音标和中英文发音

系统 SHALL 在复习正面展示卡片音标，并为清理 Markdown 后识别为中文或英文的任意卡片正面提供发音按钮。中文内容 SHALL 使用 `zh-CN` 朗读，英文内容 SHALL 使用 `en-US` 朗读，中英文混排内容 SHALL 按连续同语言片段分段朗读。发音 SHALL 仅由用户点击按钮触发，SHALL NOT 自动播放。其他语言、无法识别语言或浏览器不支持语音合成的卡片 SHALL 不显示发音按钮。

#### Scenario: 英语单词卡复习正面

- **WHEN** 用户复习一张带有 `phonetic` 的英语单词卡
- **THEN** 正面显示音标和发音按钮
- **AND** 用户点击发音按钮后使用美式英语朗读该单词
- **AND** 系统不会在卡片出现时自动播放

#### Scenario: 英文短语卡复习正面

- **WHEN** 用户复习一张正面为英文短语但 `phonetic` 为 `NULL` 的卡片
- **THEN** 正面不显示音标
- **AND** 正面仍显示发音按钮
- **AND** 用户点击发音按钮后使用美式英语朗读整个英文短语

#### Scenario: 中文卡片复习正面

- **WHEN** 用户复习一张正面为中文句子的卡片
- **THEN** 正面不显示音标
- **AND** 正面显示发音按钮
- **AND** 用户点击发音按钮后使用中文普通话朗读

#### Scenario: 中英文混排卡片复习正面

- **WHEN** 用户复习一张正面同时包含中文和英文片段的卡片
- **THEN** 正面显示发音按钮
- **AND** 用户点击发音按钮后分别按 `zh-CN` 和 `en-US` 朗读对应片段

#### Scenario: 其他语言卡片复习正面

- **WHEN** 用户复习一张正面无法识别为中文或英文的卡片
- **THEN** 复习正面不显示发音按钮
- **AND** 如果卡片是单个英文单词，音标仍可正常显示

#### Scenario: 浏览器不支持语音合成

- **WHEN** 浏览器不提供语音合成能力
- **THEN** 系统隐藏发音按钮
- **AND** 音标仍可正常显示
