## ADDED Requirements

### Requirement: JSON 数组解析预览

系统 SHALL 允许用户从卡组详情页粘贴 JSON 数组或上传 `.json` 文件，并将原始内容提交给后端解析。系统 SHALL 接受对象数组 `[{"front":"正面","back":"背面"}]`，逐项返回规范化后的正面、背面、重复状态和错误列表，并提供有效、重复、无效数量汇总。正面为必填且去首尾空白，背面缺失或空白时归一化为空字符串。无效 JSON 或非数组根节点 SHALL 被拒绝并显示可见错误。

#### Scenario: 粘贴 JSON 后成功解析

- **WHEN** 用户在卡组详情页粘贴包含有效对象数组的 JSON 并点击解析
- **THEN** 系统展示逐项预览，每项包含正面、背面和解析状态

#### Scenario: 文件上传与粘贴共用解析

- **WHEN** 用户选择一个 `.json` 文件并点击解析
- **THEN** 系统读取文件内容并返回与粘贴输入相同的逐项预览

#### Scenario: 单行无效仍可预览

- **WHEN** JSON 数组中存在正面为空或缺少正面的项
- **THEN** 系统仍返回该行预览，并标记该行无效及对应错误

#### Scenario: 无效 JSON 被拒绝

- **WHEN** 用户提交不是合法 JSON 数组的内容
- **THEN** 系统拒绝解析并显示解析失败错误

### Requirement: 可编辑导入预览

系统 SHALL 允许用户在导入前编辑预览中的每张卡片，包括修改正面和背面、删除行和新增空行。用户编辑后 SHALL NOT 需要重新解析即可继续导入，但系统 SHALL 在最终导入时重新校验全部内容。

#### Scenario: 修改预览卡片

- **WHEN** 用户在预览中修改某张卡片的正面或背面
- **THEN** 导入请求使用修改后的内容，且该行状态随内容更新

#### Scenario: 删除和新增预览行

- **WHEN** 用户删除一个预览行或新增一个空行
- **THEN** 最终导入只包含保留的行，并允许用户为空行补充内容

### Requirement: 批量导入卡片

系统 SHALL 允许用户将编辑后的预览内容批量导入当前卡组。导入的卡片 SHALL 作为新卡追加到卡组末尾，SHALL 保留预览中的原始顺序，并 SHALL 返回成功创建数量与跳过的现有重复数量。

#### Scenario: 批量导入成功

- **WHEN** 用户点击导入且所有卡片均有效
- **THEN** 系统创建全部卡片，卡片列表刷新后显示新增卡片

#### Scenario: 与现有卡片去重

- **WHEN** 预览中包含与当前卡组已有卡片正面和背面完全相同的卡片
- **THEN** 系统跳过该卡片，不创建新记录，并在导入结果中报告跳过数量

#### Scenario: 导入顺序保留

- **WHEN** 用户导入按 A、B、C 排列的多张卡片
- **THEN** 新卡片在卡组中按 A、B、C 顺序排列

### Requirement: 导入校验与原子写入

系统 SHALL 在最终导入时重新校验每张卡片的正面和背面，并 SHALL 校验用户对卡组的访问权限。如果任一张卡片无效或卡组不存在，系统 SHALL 拒绝整批导入且不创建任何卡片。

#### Scenario: 无效行阻止整批导入

- **WHEN** 导入内容中至少有一行正面为空
- **THEN** 系统拒绝整批导入，显示行级错误，且没有卡片被创建

#### Scenario: 无权访问卡组

- **WHEN** 用户尝试向不属于自己的卡组导入卡片
- **THEN** 系统拒绝导入并返回卡组不存在错误

### Requirement: 导入输入限制

系统 SHALL 限制单次导入的原始 JSON 大小和卡片数量，超出限制时 SHALL 拒绝请求并显示可见错误。

#### Scenario: 超出卡片数量限制

- **WHEN** 用户提交超过单次导入上限的卡片数量
- **THEN** 系统拒绝解析并提示减少卡片数量

#### Scenario: 超出原始内容大小限制

- **WHEN** 用户提交超过原始 JSON 大小上限的内容
- **THEN** 系统拒绝解析并提示缩小文件或粘贴内容
